# XY-interface

An interactive web app for psychoacoustics experiments. Sounds are represented with clickable, draggable colored dots that can be placed into an X-Y plane to indicate similarity.

## Future Features:

* Ability to highlight each dot, select its color
* "Record" ("Finish"?) button that takes the information about the dots' X-Y positions and logs them out to a data file along with user ID, time to complete (?), number of plays for each sound
  * Record positions of canvas edges, too
* Move from one page of these to another, each with a different set of sounds, some according to Bill Gaver's sound source classification system, subset of transitivity stimuli (just references?), recorded musical sounds? Other recorded environmental sounds?
* Eight sounds, or a flexible number of sounds
  * Dynamically create dots for each audio file in the audio folder? Have each page and associated data store dynamically generated based on each subfolder within the audio folder?
